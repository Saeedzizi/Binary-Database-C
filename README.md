# 🗄️ Binary Database Engine (C Language)

یک سیستم مدیریت دیتابیس سطح پایین (Low-level) که با زبان **C** طراحی شده تا سرعت و امنیت فایل‌های باینری را به نمایش بگذارد. این پروژه با الهام از اصول دوره **CS50** ساخته شده است.

---

## ✨ ویژگی‌های کلیدی (Features)

* **💾 ذخیره‌سازی باینری**: برخلاف فایل‌های متنی معمولی، داده‌ها به صورت بایت‌های فشرده ذخیره می‌شوند که حجم را به شدت کاهش می‌دهد.
* **🔍 جستجوی بهینه**: استفاده از الگوریتم پیمایش سریع برای پیدا کردن مخاطبین در کمترین زمان ممکن.
* **🛠️ عملیات کامل CRUD**: قابلیت افزودن (Create)، نمایش (Read) و جستجوی داده‌ها.
* **🧠 مدیریت حافظه**: استفاده بهینه از `struct`ها و پوینترها برای تعامل مستقیم با RAM.
